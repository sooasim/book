## 2. 상호참조 검증 (OCES 03 §3.3)

- `crossref.find_references`가 본문에서 "3장", "제9장", "2절" 같은 참조를 추출(연도 등 오탐 배제).
- `validate_references`/`crossref_report`가 챕터 수 범위를 벗어난 참조를 **위반**으로 표시.
- `qa_report`에 `crossref` 섹션 + 게이트 19 추가. 예: 5장 책에서 "제9장 참조" → 위반.
- 챕터 수를 알 수 없으면 `checked=False`로 스킵.

## 3. 잡 중간 재개 (OCES 02 §5 체크포인트)

- 가장 비싼 단계인 **생성(outline+write)** 산출(원고·목차)을 `project["_snapshot"]`에 영속화.
- `resume_job`은 스냅샷이 있으면 원고/목차를 복원하고 **write 단계부터(생성 생략)** 재개(`mode="mid"`),
  없으면 처음부터 결정적 재실행(`mode="full"`).
- 완료(export) 시 스냅샷 정리. 재개 시 생성 비용·시간 절약(실모델일수록 효과 큼).
