구현체: [`apps/ebook_publisher/selenium_bot/`](../apps/ebook_publisher/selenium_bot/) · 레지스트리: `apps/ebook_publisher/platform_registry_global.csv`

## 0. 안전 경계 (가장 중요)

이 저장소의 일관된 원칙(docs/00~14, `semi_macro_browser`)을 그대로 따른다.
**자동화는 "폼 자동 채움 · 파일 업로드 · 검수"까지만** 하고, 아래는 **사람이 직접** 한다(코드가 절대 자동 실행하지 않음):

> 회원가입 최종 완료 · CAPTCHA · 이메일/휴대폰 본인인증 · 신원/사업자 인증 ·
> 약관 동의 · 저작권/출판권 확인 · AI 사용 고지 · 독점 계약 · 세금/정산 · 가격 확정 · **최종 게시(Publish)**

이유: 완전 무인 자동가입·무인 게시는 (1) 거의 모든 플랫폼 약관 위반, (2) CAPTCHA/본인인증 우회 필요,
(3) 계정 영구정지·법적 책임, (4) 'AI 스팸 도서 범람'으로 분류되어 차단. 위반 시 계정·매출을 모두 잃는다.
→ 그래서 **반자동(자동화 레벨 3)**: 준비·입력은 자동, 책임 단계는 사람. 가치의 대부분을 안전하게 얻는다.
안전 강제는 `gates.py`(`HUMAN_GATES`, `guard_action`)와 `assistant`의 분기로 코드 레벨에서 보장된다.

## 1. 요구사항 매핑(사용자 요청 → 구현)

| 요청 | 구현 |
|---|---|
| 한 번 로그인하면 자동 로그인 유지 | 플랫폼별 Chrome 영속 프로필(`profile_store.profile_dir_for`) — 세션 재사용 |
| 사이트마다 구조 파악 + 필요 양식 준비 | `inspector.py` — 게시 페이지 DOM 폼 자동 탐지 → 한/영 키워드로 필드 매핑 학습 |
| 기본정보 한 번 입력 → 모든 곳 자동 입력 | `profile_store`(단일 기본정보) + `batch.prepare_all`(전 플랫폼 일괄 계획) |
| 프로그램 생성 전자책 자동 게시 | studio 산출 EPUB/표지 → `publish_plan` → `assistant` 폼 채움·업로드(최종 게시만 사람) |
| 전 세계 사이트 수집 | `platform_registry_global.csv`(49개) + `collector` 프로버(도달성/폼 확인) |

## 4. 워크플로(로컬 PC)

```powershell
# 0) 한 번만: 기본정보 입력(이후 모든 플랫폼에 자동 적용)
python -m selenium_bot.cli profile --set-book book.json --set-publisher pub.json --base C:\oces

# 1) 전 세계 플랫폼 확인
python -m selenium_bot.cli list --region kr --verbose

# 2) 단일 기본정보 → 전 플랫폼 게시 계획 일괄 생성(브라우저 불필요)
python -m selenium_bot.cli plan-all --base C:\oces --epub OUT\book.epub --cover OUT\cover.png --out out_plans

# 3) (최초 1회/사이트) 구조 파악 + 로그인: 브라우저가 열리면 직접 로그인 후 게시 폼에서 Enter
python -m selenium_bot.cli inspect --platform amazon_kdp --base C:\oces

# 4) 반자동 게시: 폼 자동 채움 + EPUB/표지 업로드 → 약관/최종 게시만 직접 클릭
python -m selenium_bot.cli assist --platform amazon_kdp --book-json book.json --epub OUT\book.epub --cover OUT\cover.png --base C:\oces
```

- **자동 로그인 유지**: `--base` 아래 `sessions/{platform}` 에 Chrome 프로필이 보존되어, 한 번 로그인하면
  다음 실행부터 로그인 단계를 건너뛰고 바로 입력/업로드로 진입한다(이후 '출판 즉시 등록'에 근접).
- 첫 사이트는 `inspect` 로 입력칸 매핑을 학습해 두면 `assist` 가 정확히 채운다(매핑은 `mappings/`에 누적 학습).

## 5. PowerShell 실행기

`RUN_SELENIUM_LIST.ps1` · `RUN_SELENIUM_PLAN_ALL.ps1` · `RUN_SELENIUM_INSPECT.ps1` · `RUN_SELENIUM_ASSIST.ps1`
(INSPECT/ASSIST 는 `requirements-selenium.txt` 자동 설치 후 실행).

## 6. 테스트/품질

- selenium 미설치 환경에서도 **123개 테스트 통과**(레지스트리/수집/게이트/매핑/계획/가입/어시스턴트/프로필/인스펙터/배치).
- 안전 단언 포함: 어시스턴트는 human_gate 단계에서 브라우저를 호출하지 않음, 알 수 없는 액션 차단,
  가입 계획에 비밀번호/세금/정산/캡차 자동 단계가 없음, 모든 계획의 마지막은 `final_submit`(사람).
- 실제 브라우저 구동(inspect/assist/collect)은 사용자의 로컬 PC에서 selenium 설치 후 수행.

## 7. studio 파이프라인과의 연결

studio(`compose_book`)가 만든 `files['epub']`/`files['cover']` → `publish_plan`/`assist` 의 업로드 단계로 투입.
즉 "프로그램에서 생성한 전자책"이 그대로 게시 보조 대상이 된다.
