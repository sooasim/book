### M0 — 기반 정비 (1주)
- 저장소 구조 확정(`apps/`, `docs/`, `projects/`), `.gitignore` 적용.
- 도구 설치: Pandoc, calibre, Java JRE, Sigil (`apps/ebook_publisher/scripts/install_ebook_toolchain.ps1`).
- `app.py`를 라우터 분리 가능 구조로 정리.
- **완료 기준**: 도구 점검 그린, 기존 대시보드 정상.

### M1 — 윤문기 코어 (2~3주)
- 입력 어댑터(DOCX/MD) + 정규화 + 분할.
- **[필수] 600항목 체크리스트 적재**: `build_checklist.py`로 `checklist_600.json` 생성 → `checklist_run` 초기화.
- 교정 규칙엔진(띄어쓰기·맞춤법·부호) → `report.json`/`diff.html`, `rules`(114) 항목 자동 판정.
- 수락/거절 반영 → `refined.md`, `/api/refine*` + 체크리스트 검토 UI.
- **체크리스트 게이트 강제**: `complete=false`면 다음 단계 차단.
- **완료 기준**: 샘플 원고에서 교정 제안 생성·수락·되돌리기 동작, `rules` 모드 결정성 회귀 통과, **600항목 전수 상태 기록 및 게이트 차단 동작**.

### M2 — 변환·검수 (2주)
- Builder: Pandoc EPUB 변환 + 표지 규격검사 + TOC.
- Reviewer: EPUBCheck 자동 실행·리포트.
- `/api/build`·`/api/review` + UI 버튼.
- **완료 기준**: 윤문본→EPUB→EPUBCheck pass, 표지 규격검사 동작.

### M3 — 통합 오케스트레이션 (1~2주)
- 윤문 메타 → `book_metadata.csv` 자동 채움.
- Orchestrator 원클릭(refine→build→review→packs).
- 단계 실패 시 부분 재시작.
- **완료 기준**: 초고 1편 → 제출팩까지 원클릭(사람 게이트 유지).

### M4 — 고도화 (지속)
- 문체/용어/가독성 모듈, 사용자 사전/프로파일.
- (옵션) 로컬/외부 LLM 하이브리드.
- 국내 입점 신청서 자동 채움, 판매 URL/심사상태 수집.
- 시리즈 일괄, 가격 통화 환산.

### M5 — v2.0 멀티에이전트·정직 봉인 (제로존 방법론)
- Hard-Fail 린터(`lint_text.py`)를 윤문 청크 파이프라인에 연동(재작업 루프).
- 7-에이전시(A/B/C/E/F/G/J) 정의 + AutoGen/CrewAI 그룹챗 오케스트레이션.
- 정직 봉인 마커(★/◑) 데이터 모델·인간 결재 UI(`◑`만 순회 Sign-off).
- 다중 사이클(R1 구조 → R2~R5 윤문 → J-check) + 수렴 조건.
- **완료 기준**: 대형 샘플에서 ◑ 결재만으로 출간 PASS 도달, Hard-Fail 0 보장.

### M6 — Lemma 그래프·전수 동기화
- L1~L300 좌표 추출 + 의존성 그래프(Neo4j/JSON) + 프롬프트 주입.
- 설정 변경 시 연쇄 갱신(Cascade Sync) 큐.
- **완료 기준**: 1페이지 변경이 연결 좌표 전수에 동기화 알림, `cross_ref_desync` 게이트 동작.

## 4. 품질 기준 (Definition of Done)

### 공통
- 단계 산출물은 JSON 리포트로 검증 가능.
- 사람 게이트(약관/인증/최종 제출/의미변경)는 자동 통과 0건.
- 새 코드에는 골든/회귀 테스트 동반.

### 윤문기
- `rules` 모드 동일 입력→동일 출력(결정성).
- 모든 제안에 `rule_id`·근거·확신도·수락 이력.
- `semantic`/`manual` 자동 반영 금지(테스트로 보장).
- **[필수] 600항목 체크리스트 전수 적용**: 모든 항목 상태 기록, `fail`/`pending` 잔존 시 출판 차단(테스트로 보장). 분야 비해당은 `na`+사유.

### 변환·검수
- EPUBCheck pass 비율 ≥ 95%.
- 표지 규격 위반은 fail 또는 명시 경고.

### 출판
- 책 1권 추가 시 제출팩 자동 생성.
- 누락/독점 충돌/AI 고지 경고 표면화.

## 5. 테스트·CI 권장

- 로컬 우선이라 무거운 CI는 선택. 최소: `pytest`로 규칙엔진·스키마 검증.
- 회귀: 대표 원고 스냅샷 diff.
- 웹 세션용 SessionStart 훅으로 의존성·린트 보장(선택).

## 6. 인계(Handoff) 절차

다른 AI/개발자가 이어받을 때 순서:
1. `docs/00→05` 정독.
2. `apps/ebook_publisher/05_다른AI_에이전트_작업지시서.md`와 `agent_task_pack.json` 확인.
3. `scripts/check_ebook_toolchain.ps1`로 도구 점검 → 부족 시 사용자 승인 후 설치.
4. M0부터 마일스톤 순서로 진행, 각 단계 완료 기준 충족 시 커밋.
5. 사람 게이트·안전 경계 절대 우회 금지.
