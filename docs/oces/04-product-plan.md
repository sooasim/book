# OneClick eBook Studio — 프로그램 기획서 (Product Plan)

문서 버전: 1.0 · 상태: Draft

---

## 1. 제품 한 줄 정의
제목과 주제만 입력하면 AI가 목차→집필→교정→조판→출간 파일까지 자동으로 만들어 주는 **원클릭 전자책 제작 스튜디오**.

## 2. 타깃 사용자 / 페르소나

| 페르소나 | 목표(JTBD) | 현재 고통 |
|----------|------------|-----------|
| 1인 창작자/코치 "지은" | 자신의 지식을 책으로 빠르게 | 집필 시간 부족, 조판 모름 |
| 마케터 "현우" | 리드 마그넷 eBook 대량 제작 | 외주 비용·리드타임 |
| 기업 교육담당 "수아" | 사내 매뉴얼 표준화 | 작성 인력·일관성 |
| 출판 기획자 "민" | 컨셉 빠른 검증 | 초안 제작 비용 |

## 3. 핵심 사용자 시나리오 (User Flow)

```
1. 로그인 → [새 프로젝트]
2. 입력: 제목, 주제, (옵션) 독자층/톤/분량/언어/참고자료 업로드
3. [원클릭 생성] 클릭 → 진행 화면(단계별 실시간 스트리밍)
   outline ▸ write(3/12) ▸ edit ▸ fact-qa ▸ layout ▸ export
4. (옵션) 중간 체크포인트에서 목차 확인/수정 → 재개
5. 미리보기: 챕터별 본문 확인, 부분 수정 또는 [이 챕터 재생성]
6. [내보내기] EPUB / PDF / DOCX / Markdown 다운로드
7. 품질 리포트(일관성/가독성/근거) 확인
```

## 4. 기능 명세 (Feature Spec)

### 4.1 MUST (MVP, v1)
- 프로젝트 생성/저장 (현 스텁 `POST /api/projects` 확장)
- 목차 자동 생성 + 사람 수정
- 챕터 본문 자동 집필(일관성 캐리오버)
- Markdown / EPUB 내보내기
- 진행 상태 표시

### 4.2 SHOULD (v2)
- 잡 큐 비동기 + SSE 실시간 진행
- 단계별 재생성, 챕터 단위 재생성
- 품질 게이트(사실/표절/가독성/금칙어)
- PDF/DOCX 내보내기
- HITL 체크포인트(목차 승인 후 진행)

### 4.3 COULD (v3+)
- RAG 자료 업로드(PDF/URL) 기반 집필
- 표지/삽화 이미지 생성
- Style Bible 편집 UI(용어집/톤/페르소나)
- 협업/코멘트/버전관리
- 다국어 번역 출력

### 4.4 WON'T (현 단계 제외)
- 장편 소설 플롯/캐릭터 일관성 엔진(별도 트랙)
- 종이책 인쇄 입고(POD) 연동
- 마켓플레이스 직접 판매

## 5. 비기능 요구사항 (NFR)
- **성능**: 1만 단어 초안 P50 < 20분.
- **신뢰성**: 워커 크래시 시 체크포인트 재개, 잡 유실 0.
- **비용**: 권당 토큰 예산 상한 가드.
- **보안**: 멀티테넌시 격리, 서명 URL, 프롬프트 인젝션 방어.
- **관측성**: 단계별 지연/토큰/실패율 대시보드.

## 6. 정보구조 / 화면 목록
- 대시보드(프로젝트 목록·상태)
- 프로젝트 생성/설정(제목·주제·옵션·자료)
- 컴포즈 진행(스트리밍 타임라인)
- 에디터(목차 트리 + 챕터 본문, 인라인 재생성)
- 내보내기/다운로드 + 품질 리포트
- 설정(스타일 바이블·계정·쿼터)

## 7. 로드맵 / 마일스톤

| 버전 | 범위 | 산출물 | 완료 기준(DoD) |
|------|------|--------|----------------|
| **v0 (현재)** | 스켈레톤 | API 스텁·Web 스캐폴드 | 빌드/배포 됨 |
| **v1 MVP** | 동기 단순 파이프라인 | 제목·주제→목차→본문→EPUB | 1권 end-to-end 생성 |
| **v2** | 비동기·게이트·HITL | 잡 큐·SSE·재생성·PDF | 안정적 장시간 잡, 품질 게이트 |
| **v3** | RAG·이미지·협업 | 자료 업로드·삽화·버전 | 근거 기반 집필 |
| **v4** | SaaS화 | 결제·쿼터·다국어 | 외부 사용자 온보딩 |

## 8. KPI / 성공 지표
- TTFD(1만 단어) P50 < 20분
- 검수 후 출판률 ≥ 40%
- 자동 일관성 점수 ≥ 0.85
- 단계 평균 재시도 < 1.5회
- 권당 토큰 비용 목표 이내

- [ ] 챕터 재생성 API + 에디터 인라인

## 10. 의존성 / 가정 / 미결정
- **가정**: 비소설(실용/가이드/교재) 우선. 소설은 후속.
- **의존**: LLM API 키·쿼터, 표절검사 외부 API(선택), 렌더러(pandoc) 설치.
- **미결정(사용자 확인 필요)**: 1차 타깃 콘텐츠 유형, 우선 출력 포맷, LLM 예산/공급자, 다국어 범위.
