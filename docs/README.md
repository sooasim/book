## 한눈에 보는 처리 흐름

```
원고(.docx/.md)
   └─[Refiner 윤문기]──▶ 교정·문체·일관성·가독성 + 메타추출 (사람 수락)
        └─[Builder]────▶ EPUB / PDF (Pandoc·calibre, 표지·TOC)
             └─[Reviewer]─▶ EPUBCheck·미리보기·규격검사
                  └─[Publisher]─▶ 14개 플랫폼 제출팩 + 자동입력 JSON
                       └─[BrowserAssistant]─▶ 입력 보조(최종 제출 앞 정지)
                            └─ 사람 최종 제출 → StatusLedger 기록
```

기존 동작 MVP는 [`../apps/ebook_publisher/`](../apps/ebook_publisher/) 참조.
