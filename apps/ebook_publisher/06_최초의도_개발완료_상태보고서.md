# 최초 의도 기준 개발 상태 보고서

작성일: 2026-06-07

## 1. 최초 의도

사용자의 최초 의도는 다음과 같았다.

- 작성한 전자책을 여러 국내/해외 사이트에 등록하고 싶다.
- 앞으로 계속 만드는 전자책을 원클릭에 가깝게 등록하고 싶다.
- 사이트 가입과 책 등록을 자동화하고 싶다.
- 별도 Chromium 브라우저에서 기본정보를 입력받고 페이지를 인식해 자동 입력하는 반매크로를 원한다.
- 사용자 편의성을 극대화한 UI와 프로그램 구조를 원한다.
- 출판 기능은 다른 폴더의 별도 프로그램으로 분리하길 원한다.

## 2. 현재 구현 완료

현재 `전자책출판_독립프로그램` 폴더는 독립 로컬 앱으로 동작한다.

완료된 기능:

- 로컬 웹앱 서버: `app.py`
- 통합 UI: `ui/one_click_publisher_dashboard.html`
- 실행기: `RUN_APP.ps1`
- 브라우저 자동 열기 실행기: `RUN_PUBLISHER_DASHBOARD.ps1`
- 제출팩 생성 실행기: `RUN_GENERATE_SUBMISSION_PACK.ps1`
- KDP 반매크로 실행기: `RUN_KDP_ASSIST.ps1`
- 플랫폼 14개 레지스트리
- 책 메타데이터 CSV
- 출판 상태 CSV
- 제출 큐 CSV
- 플랫폼별 제출팩 생성기
- 별도 Chromium 반매크로
- 입력칸 학습 매핑 폴더
- 도구 점검/설치 스크립트
- 다른 AI 인계용 JSON/지시서

## 3. 로컬 앱 기능

브라우저 주소:

`http://127.0.0.1:8765`

화면에서 가능한 것:

- 책 수, 플랫폼 수, 제출 파일 수, 누락 파일 수 확인
- 책 목록 확인
- 선택한 책의 플랫폼별 진행 상태 확인
- 표지/원고 누락 경고 확인
- AI 고지/KDP Select/사람 확인 게이트 확인
- 제출팩 생성 버튼 실행
- 도구 점검 버튼 실행
- 책 정보 수정
- KDP 반매크로 실행 명령 확인

API 검증 결과:

- `/api/state`: 정상
- `/api/generate-packs`: 정상
- `/api/assist-command`: 정상

검증 당시 상태:

- 책: 1권
- 플랫폼: 14개
- 제출 파일: 58개
- KDP 반매크로 명령 구성: 18개 인자

## 4. 자동화 수준

구현된 자동화:

- 책 메타데이터 기반 제출팩 자동 생성
- 플랫폼별 Markdown/JSON 제출자료 생성
- 파일 누락 확인
- 출판 상태표 표시
- 별도 Chromium으로 사이트 페이지 열기
- 페이지 입력칸 인식
- 제목/저자/소개문/키워드/가격/파일칸 자동 입력 보조
- 입력칸 매핑 학습 저장

의도적으로 자동화하지 않는 것:

- 비밀번호 입력
- 본인인증
- CAPTCHA
- 약관 동의
- 독점 계약 선택
- 세금번호/계좌번호 저장
- 최종 출판/제출 버튼 클릭

이 제한은 미완성이 아니라 안전 설계다.

## 5. 사용자 편의성 수준

현재 수준:

- CLI만 있는 상태에서 로컬 웹앱 단계로 올라왔다.
- 제출팩 생성은 UI 버튼으로 가능하다.
- 도구 점검도 UI 버튼으로 가능하다.
- 책 정보 수정도 UI에서 가능하다.
- KDP 반매크로는 아직 별도 실행 명령을 사용자가 실행하는 방식이다.

아직 남은 개선:

- KDP 반매크로를 UI 버튼에서 별도 PowerShell 창으로 직접 실행
- 플랫폼별 실제 페이지 매핑 안정화
- 표지 생성/리사이즈 기능
- EPUB 변환/Pandoc/calibre 파이프라인
- 국내 입점 신청서 자동 채움
- 판매 URL/심사상태 자동 수집

## 6. 실행 방법

로컬 앱 열기:

```powershell
powershell -ExecutionPolicy Bypass -File .\전자책출판_독립프로그램\RUN_PUBLISHER_DASHBOARD.ps1
```

서버만 실행:

```powershell
powershell -ExecutionPolicy Bypass -File .\전자책출판_독립프로그램\RUN_APP.ps1
```

제출팩 생성:

```powershell
powershell -ExecutionPolicy Bypass -File .\전자책출판_독립프로그램\RUN_GENERATE_SUBMISSION_PACK.ps1
```

KDP 반매크로:

```powershell
powershell -ExecutionPolicy Bypass -File .\전자책출판_독립프로그램\RUN_KDP_ASSIST.ps1
```
