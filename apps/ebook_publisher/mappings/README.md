# 브라우저 반매크로 학습 매핑

이 폴더에는 플랫폼별 입력칸 매핑이 저장됩니다.

예:

- `amazon_kdp.json`
- `draft2digital.json`
- `gumroad.json`

처음 실행할 때는 페이지를 스캔해서 제목, 저자, 소개문, 가격 같은 입력칸 후보를 찾습니다. 저장된 매핑이 생기면 다음 실행부터 같은 플랫폼에서 더 빠르게 자동 입력합니다.

주의:

- 비밀번호, 주민번호, 계좌번호, 세금번호는 저장하지 않습니다.
- 약관 동의, 본인인증, CAPTCHA, 최종 제출 버튼은 자동 처리 대상이 아닙니다.
