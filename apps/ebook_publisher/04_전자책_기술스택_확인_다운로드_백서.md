# 전자책 기술스택 확인 및 다운로드 백서

작성일: 2026-06-07

## 1. 목적

## 7. 다른 AI에게 줄 최우선 명령

다른 AI는 먼저 다음을 수행한다.

1. `scripts/check_ebook_toolchain.ps1`을 실행해서 도구 상태를 확인한다.
2. 부족한 도구가 있으면 사용자에게 확인한 뒤 `scripts/install_ebook_toolchain.ps1 -Install`을 실행한다.
3. `book_metadata_template.csv`의 실제 책 정보와 파일 경로를 점검한다.
4. `scripts/generate_submission_pack.py`로 제출팩을 재생성한다.
5. `scripts/semi_macro_browser.py --mode inspect`로 대상 플랫폼 페이지를 먼저 검사한다.
6. 문제가 없을 때만 `--mode assist`로 자동 입력을 보조한다.
7. 약관 동의, 본인인증, CAPTCHA, 최종 제출은 사용자가 직접 하게 둔다.

Windows에서 PowerShell 실행 정책 때문에 `.ps1` 직접 실행이 막히면 다음 형식으로 실행한다.

```powershell
powershell -ExecutionPolicy Bypass -File .\전자책_출판자동화\scripts\check_ebook_toolchain.ps1
powershell -ExecutionPolicy Bypass -File .\전자책_출판자동화\scripts\install_ebook_toolchain.ps1 -Install
```
