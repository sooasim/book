# 출판 자동화 설계

## 목표

앞으로 계속 만드는 전자책을 한 번의 메타데이터 입력으로 국내/해외 출판 채널에 반복 등록할 수 있게 만든다.

## 자동화 경계

완전 자동화 가능한 영역:

- 책 메타데이터 표준화
- 원고/표지/샘플 파일 존재 확인
- 플랫폼별 제출 체크리스트 생성
- 소개문, 키워드, 카테고리, 가격표 변환
- 브라우저 자동 입력용 데이터 파일 생성
- 배급사용 CSV/엑셀 양식 생성
- 등록 현황 대시보드 생성

사람 확인이 필요한 영역:

- 회원가입, 본인인증, 사업자/출판사 계약
- 세금 정보, 정산 계좌, 주민/사업자 정보 입력
- CAPTCHA, 이메일/휴대폰 인증
- 약관 동의, 독점 계약, KDP Select 선택
- 최종 제출 버튼

## 권장 구조

1. `book_metadata.csv`에 책 정보를 한 번만 입력한다.
2. 시스템이 파일 검증과 누락 항목 검사를 수행한다.
3. 플랫폼별 제출팩을 만든다.
4. 공식 API/CSV가 있는 곳은 그 경로를 우선 사용한다.
5. API가 없으면 브라우저 자동 입력을 사용하되 최종 제출은 사람이 확인한다.
6. 등록 완료 후 플랫폼별 URL, 심사 상태, 가격, 정산 조건을 `publication_status.csv`에 누적한다.

## 국내 플랫폼 전략

국내 대형 서점은 독립 작가가 버튼 하나로 바로 올리는 구조보다 출판사/공급사 입점 계약 구조가 많다. 따라서 자동화 초점은 다음 순서가 좋다.

1. 출판사 신고/사업자등록/ISBN 준비 여부 체크
2. 거래 신청서 자동 작성에 필요한 정보 묶음 생성
3. 원고/표지/도서정보/가격표 패키징
4. 담당자 이메일 또는 SCM 업로드용 폴더 생성
5. 심사/계약/등록 진행 상태 추적

우선 대상:

- 교보문고
- YES24
- 알라딘
- 리디
- 필요 시 밀리의서재/북큐브/영풍/인터파크 계열 채널 추가

## 해외 플랫폼 전략

해외는 직접 등록과 배급사 등록을 섞는 것이 좋다.

- Amazon KDP: 직접 등록. 단, KDP Select를 켜면 해당 전자책은 90일 동안 다른 디지털 판매처와 충돌할 수 있으므로 제목별로 관리한다.
- Draft2Digital: 여러 해외 서점/도서관 배급 허브로 사용.
- Google Play Books: 직접 등록 후보.
- Apple Books: EPUB 직접 등록 또는 파트너 배급.
- Kobo Writing Life: 직접 등록 후보.
- IngramSpark: 종이책/POD 중심, 전자책은 중복 유통 주의.
- PublishDrive: 대량 카탈로그/다중 스토어 관리 후보.

## 다음 구현 단계

1. 실제 출판할 책 1권의 원고/표지 파일 경로를 메타데이터에 넣는다.
2. `generate_submission_pack.py`로 제출팩을 만든다.
3. KDP용 브라우저 자동 입력 스크립트를 별도로 만든다.
4. 국내 거래 신청서 양식이 확보되면 엑셀/PDF 자동 채움 모듈을 붙인다.
5. 등록 상태 추적용 `publication_status.csv`와 간단한 로컬 대시보드를 만든다.
