# 다른 AI/에이전트 작업지시서

## 역할

너는 `C:\Users\ATA\Documents\총정리\전자책_출판자동화` 프로젝트를 이어받는 전자책 출판 자동화 에이전트다.

목표는 작성된 전자책을 여러 국내/해외 플랫폼에 등록하기 위한 파일 변환, 검수, 제출팩 생성, 브라우저 반자동 입력을 돕는 것이다.

## 절대 금지

- 비밀번호를 저장하지 마라.
- 주민등록번호, 세금번호, 계좌번호를 평문 파일에 쓰지 마라.
- CAPTCHA를 우회하지 마라.
- 본인인증을 자동 우회하지 마라.
- 약관 동의를 자동으로 누르지 마라.
- KDP Select 같은 독점 계약을 자동 선택하지 마라.
- 최종 출판/제출 버튼을 사용자 확인 없이 누르지 마라.

## 현재 파일

- `platform_registry.csv`: 사이트 목록과 자동화 수준
- `book_metadata_template.csv`: 책 정보 입력 양식
- `publisher_profile_template.csv`: 출판자 정보 입력 양식
- `scripts/generate_submission_pack.py`: 제출팩 생성기
- `scripts/semi_macro_browser.py`: Chromium 반매크로
- `scripts/check_ebook_toolchain.ps1`: 도구 설치 상태 확인
- `scripts/install_ebook_toolchain.ps1`: 필요한 도구 설치 스크립트
- `ui/one_click_publisher_dashboard.html`: 대시보드 프로토타입
- `mappings/`: 사이트별 입력칸 학습 매핑

## 먼저 실행할 명령

```powershell
cd C:\Users\ATA\Documents\총정리
powershell -ExecutionPolicy Bypass -File .\전자책_출판자동화\scripts\check_ebook_toolchain.ps1
```

## 부족한 도구 설치

사용자에게 설치 여부를 확인한 뒤에만 실행한다.

```powershell
powershell -ExecutionPolicy Bypass -File .\전자책_출판자동화\scripts\install_ebook_toolchain.ps1 -Install
```

설치 대상:

- Pandoc
- calibre
- Java JRE
- Sigil

Kindle Previewer와 Kindle Create는 Amazon KDP 공식 페이지를 열어 사용자가 직접 설치하도록 안내한다.

## 제출팩 생성

```powershell
python .\전자책_출판자동화\scripts\generate_submission_pack.py `
  --books .\전자책_출판자동화\book_metadata_template.csv `
  --platforms .\전자책_출판자동화\platform_registry.csv `
  --out .\전자책_출판자동화\out
```

## 브라우저 반매크로 검사

처음 플랫폼은 입력하지 말고 검사만 한다.

```powershell
python .\전자책_출판자동화\scripts\semi_macro_browser.py `
  --platform amazon_kdp `
  --book-id zerozone_001 `
  --mode inspect
```

검사가 괜찮으면 보조 입력을 실행한다.

```powershell
python .\전자책_출판자동화\scripts\semi_macro_browser.py `
  --platform amazon_kdp `
  --book-id zerozone_001 `
  --mode assist
```

저장된 매핑이 안정화되면 다음부터 원클릭 입력 모드를 쓴다.

```powershell
python .\전자책_출판자동화\scripts\semi_macro_browser.py `
  --platform amazon_kdp `
  --book-id zerozone_001 `
  --mode one-click
```

## 구현 우선순위

1. toolchain 점검 결과를 `toolchain_status.json`으로 저장한다.
2. Pandoc으로 DOCX/Markdown을 EPUB로 변환하는 스크립트를 추가한다.
3. calibre `ebook-convert`가 있으면 변환 결과를 한 번 더 정리한다.
4. EPUBCheck로 EPUB 오류를 검수한다.
5. 표지 파일 존재, 크기, 확장자, 해상도를 검사한다.
6. KDP 페이지 매핑을 실제 페이지 기준으로 학습한다.
7. Draft2Digital, Gumroad, Payhip 순서로 확장한다.
8. 국내 사이트는 입점서류 자동 생성과 이메일 초안 생성부터 한다.
