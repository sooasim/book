# 전자책출판 독립프로그램 시작안내

이 폴더는 논문표준학습과 분리된 전자책 출판 전용 프로그램입니다.

위치:

`C:\Users\ATA\Documents\총정리\전자책출판_독립프로그램`

## 핵심 기능

- 국내/해외 전자책 플랫폼 14개 레지스트리 관리
- 책 메타데이터 관리
- 플랫폼별 제출팩 생성
- 별도 Chromium 반매크로로 등록 페이지 자동 입력 보조
- 플랫폼별 입력칸 학습 매핑 저장
- 출판 진행 상태표 관리
- 로컬 웹앱 대시보드 제공
- 화면에서 제출팩 생성 실행
- 화면에서 도구 점검 실행
- 화면에서 책 정보 수정
- 화면에서 KDP 반매크로 명령 확인

## 바로 실행

로컬 앱 열기:

```powershell
powershell -ExecutionPolicy Bypass -File .\전자책출판_독립프로그램\RUN_PUBLISHER_DASHBOARD.ps1
```

서버만 실행:

```powershell
powershell -ExecutionPolicy Bypass -File .\전자책출판_독립프로그램\RUN_APP.ps1
```

브라우저 주소:

`http://127.0.0.1:8765`

제출팩 생성:

```powershell
powershell -ExecutionPolicy Bypass -File .\전자책출판_독립프로그램\RUN_GENERATE_SUBMISSION_PACK.ps1
```

KDP 입력 보조:

```powershell
powershell -ExecutionPolicy Bypass -File .\전자책출판_독립프로그램\RUN_KDP_ASSIST.ps1
```

## 안전 경계

이 프로그램은 다음을 자동 처리하지 않습니다.

- 회원가입 최종 완료
- 비밀번호 입력
- 본인인증
- CAPTCHA
- 약관 동의
- 독점 계약 선택
- 최종 출판/제출 버튼
- 세금번호/계좌번호 저장

이 프로그램은 반복 입력과 제출자료 준비를 자동화합니다. 법적 책임이 따르는 최종 단계는 사용자가 직접 확인합니다.
